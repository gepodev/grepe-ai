# grepe.ai

**Free, local, private, unlimited AI for Roblox creators.**

Type what you want — "a pine tree", "a red spawn part", "make that tree
choppable" — and it appears in your Roblox Studio place. The AI runs on your
own PC: no cloud, no per-token billing, and your prompts never leave your
machine.

**Website:** https://gepodev.github.io/grepe-ai/

This repository hosts the **official downloads and website only**.

## Quick start

1. Run the installer (unsigned build: SmartScreen → *More info → Run anyway*).
2. Open grepe.ai and press **Download Model** once (~2.5 GB, SHA-256 verified).
3. Join the Discord, run `/getkey`, press the **Get Key** button — the key
   arrives by DM. Paste it into the app and press **Activate**.
4. Press **Start AI Server**, then **Start Bridge**.
5. Install the Studio plugin from the Creator Store, click the grepe.ai
   toolbar button, and paste the bridge token shown in the app's Settings.
6. Type a prompt and press **Generate**. **Ctrl+Z** undoes any change.
   The **+** button attaches a reference image for the AI to match.

The desktop app updates itself automatically from this repository's releases.

## Notes

- Everything runs locally on 127.0.0.1; the only online checks are Discord
  key validation and update downloads.
- Keys are revoked automatically when you leave the Discord server.
- Windows 10/11 x64, 8 GB RAM, ~6 GB disk. No GPU required.
