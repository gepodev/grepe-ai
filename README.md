# grepe.ai

**Free, local, private, unlimited AI for Roblox creators.**

Type what you want — "a pine tree", "a red spawn part", "make that tree
choppable" — and it appears in your Roblox Studio place. The AI runs on your
own PC: no cloud, no subscription, no per-token billing, and your prompts
never leave your machine.

This repository hosts the **official downloads only**.

## Quick start

1. Install the Windows app from the link above and launch it.
2. Press **Start Bridge**, then **Join Discord** and run `/getkey` in the server.
3. Paste the key and your Discord ID into the app and press **Activate**.
4. Press **Download Model (2.5 GB)** once, then **Start AI Server**.
5. Install the Studio plugin, open it from the Plugins tab, and paste the
   pairing token shown in the desktop app.
6. Type a prompt and press **Ctrl+Enter**. **Ctrl+Z** undoes any change.

The desktop app updates itself automatically from this repository's releases.

## Notes

- Everything runs locally on 127.0.0.1; the only online checks are the free
  Discord key validation and update downloads.
- Keys last 12 hours and are free forever.
