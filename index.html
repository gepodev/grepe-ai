Up and building in 5 minutes

One installer, one plugin, one Discord key. That’s the whole setup.

1

Install the app

Run the Windows installer, open grepe.ai and click Download Model (~2.5 GB, SHA-256 verified) — or point it at a model file you already have.

2

Get your key

Join the Discord, run /getkey and press the Get Key button. The key arrives by DM. Paste it into the app and hit Activate.

3

Start the servers

Click Start AI Server, then Start Bridge. Both bind to 127.0.0.1 only. The app shows live status for each.

4

Install the plugin & build

Add grepe.ai from the Creator Store, paste the bridge token once, type a prompt and press Generate. Watch it appear in Studio.

Pick your key length

The AI itself is free and unlimited on every tier — tiers only change how long a key stays valid before you press Get Key again. Paid tiers are re-buyable: buy again any time and the time stacks on top of what you have left.
